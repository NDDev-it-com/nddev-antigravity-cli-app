# NDDev Builder

Use this skill for NDDev setup-manager design, public contract review, native
Antigravity CLI plugin packaging, and public/private harness boundary checks.

Prefer current Antigravity CLI surfaces:

- `~/.gemini/antigravity-cli/settings.json` for persistent settings.
- `~/.gemini/antigravity-cli/plugins/<name>/plugin.json` for plugin identity.
- Plugin `skills/`, `agents/`, and `rules/` directories for bundled capability.
