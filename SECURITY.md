# Security

Report security issues through GitHub private vulnerability reporting for
`NDDev-it-com/nddev-antigravity-cli-app`.

Do not include provider API keys, Antigravity CLI credentials, private
repository content, or live user configuration in reports unless explicitly
requested in a private channel.

The setup manager is target-explicit. Security reports should describe the
isolated target path used for reproduction and must not require mutating live
`~/.gemini` state.
